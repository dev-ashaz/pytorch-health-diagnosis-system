PyTorch Health Diagnosis System
Overview
A healthcare prediction system built using PyTorch and neural networks to classify breast cancer diagnostic data.

PyTorch

NumPy

30 medical features
Results
The model was trained using PyTorch and achieved high predictive accuracy on unseen test data.
